What is 5G?
Definition
5G is the fifth generation of mobile networks that enables
communication between users and digital services with high speed,
low latency, and massive connectivity.
Simple idea
It connects not only smartphones, but also cars, homes, and many
smart devices to the internet.

From 2G to 5G

▶ 3G: mobile internet
▶ 4G: high-speed multimedia and data

Key idea
5G is the new generation of mobility after 2G, 3G, and 4G.

What is the 5G Core?
Definition
The 5G Core is the central part of the network. It manages users,
sessions, routing, and communication with external services.
Where is it placed?
In real deployments, the 5G Core is hosted in operator data centers
or cloud infrastructure.

Main Network Functions
▶ AMF: manages user access and mobility
▶ SMF: manages session creation and control
▶ UPF: forwards user data (internet traffic)
▶ NRF: service registry (finds network functions)
▶ AUSF: authentication function
▶ UDM: user subscription data
▶ NSSF: selects network slices
Key idea
Each function is independent and acts like a microservice.

--- PAGE 11 ---
What are 5G Interfaces?
Definition
Interfaces are standardized communication methods between
network functions.
▶ They are defined by 3GPP
▶ They are logical (not physical cables)
▶ They use different protocols depending on the type
11 / 22

--- PAGE 12 ---
Types of 5G Interfaces
1. Service-Based Interfaces (SBI)
▶ Used between core functions
▶ HTTP/2 + JSON APIs
▶ Example: Namf, Nsmf, Nudm, Nnrf
2. Reference Point Interfaces
▶ UE and network communication paths
▶ Example: N1, N2, N3, N4
▶ Use protocols like NAS, PFCP, GTP

Why Could 5G Be Vulnerable?
▶ The 5G Core uses microservices
▶ Network functions communicate via APIs
▶ APIs are exposed inside the network
Key idea
More flexibility means a larger attack surface.

Original Security Assumption
Design assumption
The 5G Core was designed for a controlled telecom environment.
▶ Physically protected data centers
▶ Limited external access
▶ Strong network perimeter
